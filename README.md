# StockWise Frontend

**StockWise** s a modern inventory management system built with React.js and TypeScript. It provides businesses with a streamlined way to manage products, monitor stock levels, track sales, and analyze revenue — all within a clean and responsive user interface.
The application leverages powerful frontend technologies to ensure performance, scalability, and a smooth user experience.

---

## Tech Stack
- **Langauge**: TypeScript
- **Framework/Library:**  React.js
- **Libraries**: TanStack Query, TanStack Router, Shadcn( UI ), Tailwindcss, Axios( API )

---

## Getting Started

1. **Clone the Repository**

- Using HTTPS
```bash
    git clone https://github.com/Unified-Testing-Inventory-Management/frontend.git
    cd frontend
```

- Using SSH
```bash
    git clone git@github.com:Unified-Testing-Inventory-Management/frontend.git
    cd frontend
```

2. Application 
- Install the dependencies
```bash
    npm install
```
- Build the application
```bash
    npm run build
```
- Run the application
```bash
    npm run dev
```
